# PL Sweep documentation

PL Sweep is a Windows 11 x64 utility from PhaZe Logic Studios for reviewing cleanup candidates before approving changes.

This public repository contains release information and user documentation. Application source remains private. **No public release is available yet.** The guides describe the application and the installation process to use when a release is published; they do not announce an available installer.

- [Installation and updates](installation.md) — requirements, download verification, setup, and removal.
- [Usage](usage.md) — previews, browser cleanup, quarantine, scans, and risk boundaries.
- [Troubleshooting](troubleshooting.md) — warnings, browser settings, updates, and recovery.
- [Privacy](privacy.md) — local data, update connections, and sharing reports.
- [Feature screenshots](screenshots.md) — controls, empty previews, settings, and themes without personal data.
- [Licensing](licensing.md) — application and repository licensing information.

Maintainers: use the [release checklist](releasing.md) and [release notes template](release-notes-template.md) when preparing a public installer.

For project information, see the [repository README](../README.md). Use [Support](../SUPPORT.md) for help and the [Security policy](../SECURITY.md) for vulnerability reporting.
