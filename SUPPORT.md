# Support

Start with the [documentation](docs/README.md) and
[troubleshooting guide](docs/troubleshooting.md). For bugs, feature requests,
and documentation corrections, use
[GitHub Issues](https://github.com/phaze-logic/PLSweep-Releases/issues/new/choose).

## A useful bug report

Include the PL Sweep version shown in the app, Windows version and architecture,
the feature and selected options, steps to reproduce, expected behavior, actual
behavior, and relevant warning text. State whether the app was running normally
or as administrator. Redacted screenshots are helpful.

Do not upload registry backups, quarantine contents, full browser data, or
unredacted CSV reports. These can contain usernames, personal paths, application
details, and other sensitive information. Remove unrelated data before sharing
Activity Log excerpts or screenshots.

For suspected vulnerabilities, use the private contact in
[SECURITY.md](SECURITY.md). Public issues are not a suitable place for security
details or personal data.

## Feature requests and documentation

Describe the task you want to accomplish and the current limitation. Documentation
pull requests are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md). This repository
does not accept application source patches because the source is private.

Response and fix timelines depend on maintainer availability. An issue is not a
guarantee that a change will be implemented.
